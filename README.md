# Above-Water Drowning Detection

This repository implements a YOLOv11-based computer vision system for
detecting drowning events in swimming pools from above-water imagery.

## Project Structure
- training/: model training scripts
- evaluation/: metrics and plots
- inference/: demo and ensemble inference
- data/: dataset configuration (no images stored)

## Models
- Baseline YOLOv11n
- Phase 2 robustness models (turbidity, glare, occlusion, color)
- Phase 3 combined model
- Ensemble inference
